# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- Объём оперативной памяти: 2048 МБ
- Количество ядер CPU: 2
- Объём диска: 25 ГБ

## 2. Сетевые интерфейсы
- **Адаптер 1 (NAT)**: IP 10.0.2.15 (динамический). Назначение: доступ в интернет, проброс портов для SSH.
- **Адаптер 2 (Host-Only)**: IP 192.168.56.103 (динамический). Назначение: изолированная сеть для прямого доступа с хоста и работы локального доменного имени.

## 3. Правило проброса портов
- Порт хостовой системы (Windows): 2222
- Порт гостевой системы (Ubuntu): 2222
- Протокол: TCP

## 4. Учётные записи
- **student**: основная учётная запись при установке. Входит в группы: `student`, `sudo`. Аутентификация: по паролю.
- **devops**: созданная учётная запись для администрирования. Входит в группы: `devops`, `sudo`. Аутентификация: по ключу SSH (`devops_vm`).

## 5. Служба SSH
- Прослушиваемый порт: 2222
- Расположение файла конфигурации: `/etc/ssh/sshd_config.d/99-hardening.conf`
- Измененные директивы:
  - `Port 2222`
  - `PermitRootLogin no`
  - `PasswordAuthentication no`
  - `PubkeyAuthentication yes`
  - `PermitEmptyPasswords no`
  - `MaxAuthTries 3`
  - `LoginGraceTime 30`
  - `AllowUsers devops`
  - `X11Forwarding no`
  - `ClientAliveInterval 300`
  - `ClientAliveCountMax 2`

## 6. Правила межсетевого экрана
- **Политики по умолчанию**: входящие — `deny`, исходящие — `allow`.
- **Перечень правил**:
  - `2222/tcp LIMIT IN Anywhere # SSH rate-limited` (ограничение частоты подключений)
  - `80/tcp ALLOW IN Anywhere # HTTP`
  - `443/tcp ALLOW IN Anywhere # HTTPS`

## 7. Снимки состояния
- **01-clean-install**: чистовая установка Ubuntu (до внесения изменений).
- **02-keys-configured**: после настройки ключевой аутентификации и создания пользователя `devops`.
- **03-ssh-hardened**: после усиления безопасности SSH и смены порта.

## 9. Контейнеризация
- **Способ установки Docker Engine**: официальный репозиторий Docker (пакет `docker-ce`), версия 29.9.2.
- **Участники группы docker**: пользователь `devops`.
- **Расположение проекта на сервере**: `~/app`.
- **Расположение файла `.env` и его права**: `~/app/.env`, права `600`.
- **Публикуемые порты и адреса**: `127.0.0.1:5000` (приложение), порт `5432` не публикуется.
- **Именованные тома**: `app_db_data` (для данных PostgreSQL).
- **Конфигурация обратного прокси-сервера**: Nginx перенаправляет запросы с `https://devops.local/app/` на `http://127.0.0.1:5000/` (директива `proxy_pass`), передавая заголовки `Host`, `X-Real-IP`, `X-Forwarded-For`, `X-Forwarded-Proto`.
