# SVN vs Git

## 1. Почему ветвление в Git «дешёвое», а в SVN «дорогое»?
- **Git:** ветка - просто указатель на коммит. Локальная, мгновенная, без сервера.
- **SVN:** ветка - копия директории в центральном репозитории. Требует сети и commit-доступа; мерж сразу фиксируется на сервере и влияет на всех.

## 2. Можно ли в SVN коммитить без интернета?
**Нет.** SVN централизован: репозиторий один, на сервере. Коммит — отправка на сервер, без сети невозможен. Офлайн доступны только правки, `svn diff`, `svn status`.

## 3. Когда SVN предпочтительнее Git?
- **Пофайловый контроль доступа** — права на отдельные файлы и папки.
- **Жёсткий контроль доступа и аудит** — директорий-уровневые права, централизованные ревизии.
- **Уже работающая инфраструктура** — миграция дороже, чем польза.
