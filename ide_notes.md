## Сравнение Git в VS Code и терминале
### **Удобно в VS Code:**
1. **Наглядный diff** - видно, что изменилось, без `git diff`.
2. **Интерактивный стейджинг** - можно закоммитить часть файла, а не весь.
3. **Конфликты слияния** - есть встроенный merge editor.
### **Удобно в терминале:**
1. **Полный контроль и гибкость** - доступны все флаги и опции Git(включая и те, что не выведены в UI VS Code).
