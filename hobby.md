# Мой пет-проект

- Идея: Учёт расходов - добавление трат с категорией и датой, программа хранит их в CSV и показывает отчет за определенный промежуток времени по категориям.
- Стек: Java, picocli, CSV-файл.
- Цель: Повторить основы Java (ООП, коллекции, Stream API, работа с файлами и датами) и попробовать библиотеку для CLI(picocli).
